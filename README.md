# 🛍️ Mini Store

Mini Store is a full-stack e-commerce web application built with **React**, **FastAPI**, and **PostgreSQL**.

The application provides authentication, product management, categories, shopping cart functionality, and an admin dashboard for managing the store.

---

## 🚀 Technologies

### Frontend
- React
- JavaScript
- Tailwind CSS
- Axios
- Vite

### Backend
- FastAPI
- Python
- SQLAlchemy
- Pydantic
- JWT Authentication

### Database
- PostgreSQL

---

## ✨ Features

### 🔐 Authentication

The application includes:

- User Registration
- User Login
- JWT Authentication
- Protected routes
- Admin authentication
- Normal user authentication

### 👤 Normal User

A normal user can:

- Register an account
- Login
- Browse products
- Search for products
- Filter products by category
- View product details
- Add products to the shopping cart
- Manage their shopping experience

### 👑 Admin

The admin dashboard allows administrators to:

- View orders
- Manage order status
- Add products
- Delete products
- Add categories
- View available categories
- Manage product stock
- Upload product images
